The solution in this repo was built in a claude.ai chat session (Claude Opus 5.5) with a code-execution sandbox.
claude.ai has no per-chat export button; the raw export is produced from Settings → Privacy → Export data,
which emails a zip containing `conversations.json`. Add that file (or the single conversation extracted from it)
here before submitting.
